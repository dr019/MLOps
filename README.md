# Отсечка 1

**Наша легенда**: Мы аутсорсинговая компания, специализирующаяся на решении широкого спектра задач связанного с обработкой текста и преимущественно ведущей деятельность с гос. сектором. И к нам пришли из МЧС/911/и т.д.:

**Тема**: Классификация твитов(замените на комментарии в Telegram, MAX, посты в ВК) о срочных происшествиях

**Датасет**: Natural Language Processing with Disaster Tweets (https://www.kaggle.com/competitions/nlp-getting-started)

**Бизнес-цель**: Автоматически классифицировать публикуемые твиты из социальной сети X.com на наличие сообщений о срочных происшествиях, которые могут ускорить реагирование специализированных служб спасения(Пожарные службы, Полиция, Скорая помощь). Снизить нагрузку на ручную модерацию(оператора службы спасения) в регионах, где наблюдается кадровый дефицит в службах спасения. Также сбор статистики о происшествиях поможет регулировать необходимый штат спасателей в течение дня.

### Целевые метрики:
**Качество модели**:
- Accuracy ≥ 0.88 на валидации
- F1 (для класса «disaster») ≥ 0.9

**Использование в realtime**:
- Время холодного старта контейнера ≤ 3 c
- Обновление модели без даунтайма (rolling update)

**SLA**:
- Среднее время отклика P50 ≤ 400 мс, P95 ≤ 1000 мс (Даже в случае серьезных катаклизмов P95 хватит, особенно учитывая, что на том конце провода сидит диспетчер, то есть человек)

### План экспериментов:

**Базовая модель**: Tiny BERT

**Модель к которой стремимся**: Base BERT(в идеале), Small BERT(если не хватит GPU)

**Метрики**: accuracy, F1

**Что подбираем**: LR, batch_size, epochs

### Запуск обучения:

Перед запуском:
- pip install -r requirements.txt
- Проверить наличие датасета в data/train.csv

- Для игрушечной модели(Tiny BERT, на CPU): python -m src.train --config configs/train_bert_tiny.yaml --verbose
- Для боевой модели(Base BERT, на GPU): python -m src.train --config configs/train_bert_base.yaml --verbose

Логи обучения выводятся в консоль(при помощи logging)

Модель сохраняется в outputs/имя_модели/

### Запуск тестов:
>>pip install -r requirements.txt
>>export PYTHONPATH=$(pwd) #это нужно для корректной обработки модулей
